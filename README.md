# C_concept_hub
A collection of C programming examples, experiments, and Windows programming concepts implemented for learning and practice. This repository covers fundamental algorithms, file handling, memory management, IPC, socket programming, multithreading, and Windows API features.

## Functions Included

### Number & Algorithm Utilities
* `Palindrome()` – Check whether a number is a palindrome.
* `CountInteger()` – Count the number of digits in an integer.
* `Prime()` – Check whether a number is prime.
* `Sort()` – Sort numbers in ascending and descending order.
* `Reverse()` – Reverse elements in an array.
* `Fibonacci()` – Generate Fibonacci series.
* `Toss()` – Simulate a coin toss using random numbers.

### Date & Time Utilities
* `CurrentTime()` – Display current UTC and local time.
* `Timer()` – Implement a simple countdown timer.
* `EpochDate()` – Convert a date to epoch format and vice versa.

### Console Programming
* `ANSI()` – Demonstrate ANSI escape sequences and console formatting.
* `ConsoleAPI()` – Explore Windows Console API functions.

### File Handling
* `WriteToFile()` – Write data to files using different file I/O methods.
* `ReadFromFile()` – Read data from files.
* `FileMapping()` – Demonstrate memory-mapped file operations.
* `ReadLine()` – Read a specific line from a text buffer.
* `ReadLineUsingScanf()` – Read complete lines using scanf techniques.

### Memory Management
* `MemoryAlocation()` – Demonstrate malloc, calloc, and realloc.
* `MemFunction()` – Demonstrate memory manipulation functions such as memset, memcpy, memmove, memcmp, and memchr.

### Inter-Process Communication (IPC)
* `PipeServer()` – Named Pipe Server implementation.
* `PipeClient()` – Named Pipe Client implementation.

### Socket Programming
* `SocketServer()` – TCP Socket Server implementation.
* `SocketClient()` – TCP Socket Client implementation.

### System Utilities
* `DriveSpace()` – Display disk space information.
* `ZipFolder()` – Compress a folder into a ZIP archive.
* `UnzipFolder()` – Extract files from a ZIP archive.

### Multithreading
* `MultiThread()` – Demonstrate thread creation and synchronization using Critical Sections.

## Purpose
This repository serves as a personal learning sandbox for experimenting with various C programming concepts and Windows system programming techniques. Each function is designed to demonstrate a specific concept through practical implementation.
